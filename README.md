---

## 📌 Problem Statement

In corporate finance operations, companies process thousands of payments monthly across internal ERP ledgers and external bank statements. Manual reconciliation in Excel is:
- **Error-Prone & Slow:** Penny rounding, settlement delays, and missing references cause audit bottlenecks.
- **Lacks Explainability:** Raw discrepancies lack contextual explanations for why a transaction failed reconciliation.
- **No Governance:** Discrepancies lack a structured audit trail for review, assignment, and resolution.

---

## 🚀 Solution

This platform delivers an automated **6-pass Python reconciliation engine** paired with a modern **React + Express.js + MongoDB** operations web interface.

Key Capabilities:
1. **Multi-Pass Automated Reconciliation:** Matches transactions on invoice IDs while handling date offsets and amount tolerances.
2. **Explainable Exceptions:** Every non-matched record receives a human-readable explanation string generated by the engine.
3. **Financial Control Policy Engine:** Automatically flags high-value transactions ($10k+), duplicate invoices, missing references, and approval requirements ($25k+).
4. **Exception Management Queue:** Interactive workflow to review pending exceptions, attach resolution notes, and audit status (Pending → In Review → Resolved).
5. **Analytics Dashboard:** Live KPIs, status distribution pie charts, and daily volume trends powered by Recharts.
6. **Reporting & CSV Export:** Downloadable audit reports for compliance.

## 🔄 Reconciliation Methodology (6-Pass Matching)

```
Pass 1: Exact Match      ➔ Invoice ID + Amount (±$0.01) + Date (±2 days) ➔ MATCHED
Pass 2: Amount Mismatch  ➔ Invoice ID matches, but Amount Diff > $0.01 ➔ AMOUNT_MISMATCH
Pass 3: Date Mismatch    ➔ Invoice ID matches, but Date Offset > 2 days ➔ DATE_MISMATCH
Pass 4: Missing Ledger   ➔ Bank transaction exists, no Ledger match ➔ MISSING_LEDGER
Pass 5: Missing Bank     ➔ Ledger transaction exists, no Bank match ➔ MISSING_BANK
Pass 6: Duplicate Check  ➔ Invoice ID appears multiple times in source ➔ DUPLICATE
```

## 💻 How to Run the Project Locally

### Prerequisites
- Python 3.10+
- Node.js 18+
- MongoDB (optional, server auto-handles standalone mode)

### Step 1: Install Engine Dependencies & Run Test Data Generator
```bash
cd engine
pip install -r requirements.txt

# Generate synthetic benchmark dataset
python generate_test_data.py

# Run CLI engine directly
python reconcile.py --bank ../data/test/bank_statement.csv --ledger ../data/test/ledger.csv --output ../data/test/results.json
```

### Step 2: Start Backend REST API
```bash
cd ../backend
npm install
npm start
# API running on http://localhost:5000
```

### Step 3: Start React Frontend UI
```bash
cd ../frontend
npm install
npm run dev
# App running on http://localhost:3000
```
